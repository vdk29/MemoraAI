# MEMORA — два независимых дизайн-прототипа

Этап выбора направления. Рабочий src/, Supabase, production entrypoint и main не изменены. После предоставления ссылок работа над переносом в приложение останавливается до решения пользователя.

## Направления

A / Signal: спокойный монохромный desktop-инструмент. Плотная навигация, список библиотеки, быстрый ввод, боковой редактор. Визуальный мотив — тонкая непрерывная нить памяти, малый знак и концентрические линии. Приоритет: содержание и клавиатура.

B / Trace: выразительное персональное пространство. Вложенный app-frame, авторская стеклянная линза памяти, крупная верхняя композиция и асимметричная библиотека с релевантной обложкой только у заметки о MEMORA. Редактор появляется из положения выбранной карточки через Web Animations. Light использует отдельную систему светлых поверхностей с контрастной художественной композицией.

Это разные композиции, а не перекраска прежнего интерфейса. Рендерятся собственным entrypoint app.jsx и stylesheet, не импортируют компоненты действующей MEMORA.

## Что работает

Ввод и сохранение заметок, локальное редактирование и избранное, list/grid, навигация, переключение месяца и дня, поиск по заметкам, действия через Ctrl/Cmd+K с ↑/↓/Enter/Escape, демо-переписка и отправка локальных сообщений, переключение Light/Dark, переход через экран авторизации, пустая библиотека и восстановление демоданных через команды. Подтверждения действий и конечные анимации, prefers-reduced-motion, focus trap, возврат фокуса. Последние данные хранятся в отдельных localStorage namespace для A и B. Credentials не сохраняются, Auth — только демо-переход, HTTP к Supabase отсутствует.

## Материалы и проверки

`evidence/`: оба концепта × light/dark × desktop 1440×1000 / mobile 390×844 × home/auth/note/empty, плюс командная панель, 4 WebM и 4 H.264 MP4 записи реальных действий. Записи — без монтажа, без аудио, viewport iPhone не является физическим iPhone. Самостоятельная галерея evidence/index.html группирует материалы каждого направления.

`verify.mjs`: восемь полных комбинаций проверяют layout/no-overflow, ввод без потери фокуса, поиск и запуск команд, сохранение/reload, календарь, локальные сообщения, пустое состояние, демо-вход и отсутствие pageerror. `record.mjs` записывает реальные браузерные действия. Для воспроизведения нужен static server на localhost:5190 и системные Chromium/FFmpeg.

Сборка: из корня репозитория `npx vite build design-lab --base ./ --outDir /workspace/memora-prototypes-dist`. Затем `node design-lab/verify.mjs` и `node design-lab/record.mjs`. При публикации evidence копируется в соответствующую папку прототипов; ни один файл v2/ не заменяется.

## Графика и источники

Оригинальная Memory Lens создана встроенным image-generation инструментом для этой задачи; первоначальный PNG сохранён в workspace/generated_images, в UI — оптимизированный WebP 53.6 kB. Нет runtime Three.js/WebGL. Шрифты Inter взяты из @fontsource/inter 5.3.0 и размещены локально с SIL OFL (assets/fonts/LICENSE). Иконки lucide-react из существующих зависимостей. Новых зависимостей основного приложения нет. Платных внешних сервисов не использовалось.

Официальные страницы изучены 2026-11-04:
- https://www.raycast.com/ — клавиатурная эргономика, быстрые действия, цельность launcher-инструмента.
- https://linear.app/ — визуальная иерархия плотных рабочих списков и деталей.
- https://arc.net/ — исторический ориентир личного app-space. Текущая официальная страница посвящена завершению продукта; Arc не выдаётся за новый актуальный релиз.

Чужие иллюстрации, логотипы и код не копировались. Дизайн не является интеграцией с Raycast/Linear/Arc.

## Самопроверка композиции

- A: основной материал представлен без сетки одинаковых карточек; библиотека читается как рабочий список. Тонкие линии и малые иконографические контейнеры дают структуру, а не дополнительный декор. Правый rail отделён линией, не ещё одной большой панелью. Авторизация использует монохромный арт и более строгую композицию.
- B: каркас приложения и художественная верхняя композиция отличаются от A. Первый материал представлен как заметка проекта с уместной фирменной обложкой; остальные текстовые заметки не получают случайные изображения. На телефоне featured-заметка становится вертикальной, без узких колонок текста. Вход оформлен как самостоятельный art/editorial экран.
- Темы: светлая не построена CSS-инверсией; свои значения поверхностей, контраста и теней. В B тёмная художественная область намеренно остаётся контрастным акцентом в светлом приложении. Доступны Light/Dark и System; системная тема отслеживает изменения ОС.
- Движение: A использует боковой лист, B — раскрытие из геометрии выбранной карточки. В обоих действуют быстрые панели команд, появления сообщений, finite-вход графики и короткий hover. Проверен reduced motion. Интерфейсы не заявляются полностью готовыми продуктами до выбора и переноса настоящей логики.

Окончательная оценка направления остаётся за пользователем. Никакой автоматический перенос A или B в рабочую MEMORA не выполняется.
