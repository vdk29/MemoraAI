# Материалы будущего видео MEMORA

Назначение: исходники для будущего вертикального ролика 25–30 секунд. Это архив материалов, не готовый монтаж. Монтаж на компьютере бесплатными программами, субтитры, музыка с подходящей лицензией и русская озвучка — только ПОСЛЕ завершения разработки и тестирования MEMORA. Сейчас никакой монтаж не выполняется.

## Происхождение

- before/: локальный рендер HTML/CSS исходного main, commit 6400d8918bc51af3be1923f3457c7811f172b0e2. Десктоп 1440 px и мобильный 390 px. Страницы home, chat, calendar, auth. JavaScript и внешние обращения заблокированы, поэтому это визуальный архив, а не подтверждение работоспособности старого сайта. memoraAuth установлен исключительно в архивном браузерном контексте для показа старого HTML. Прежний Supabase не затрагивался.
- after/: реальные скриншоты нового интерфейса. Данные авторизованных экранов — UI-фикстуры. Файлы с fixture в имени дополнительно показывают демонстрационную заметку. Не представлять их как материалы реального пользователя.
- clips/note-create-favorite-calendar-fixture.webm: непрерывная запись реальных браузерных действий на мобильном viewport 390×844: кабинет → редактор → ввод текста → сохранение заметки → избранное → следующий месяц календаря. Сеть Supabase заменена локальными ответами. Это запись интерфейса с фикстурой, НЕ live end-to-end демонстрация Supabase и НЕ симуляция действий видеомонтажом.
- development/: редактор в процессе ввода и журнал этапов. Дополнять по мере разработки.

## Хранение

Папка находится в корне репозитория рядом с src, не в public. Vite не копирует её в dist; проверено после сборки. Исходный GitHub-репозиторий публичен, поэтому здесь допустимы только демонстрационные данные, без токенов, email, личных переписок и секретов.

scripts/capture-video-assets.mjs воспроизводит текущую съёмку: старый git archive main локально на :5180, новый Vite на :5173; Chromium и уже установленный системный FFmpeg. Никакие платные сервисы не использовались, новые монтажные программы не устанавливались. Монтажный MP4 не создавался.
