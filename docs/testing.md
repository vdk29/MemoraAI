# Проверки и ограничения

## Проверено 2026-11-03

- npm run build: TypeScript и production-сборка прошли.
- npm audit --omit=dev: 0 известных уязвимостей.
- Supabase Security Advisor: 0 замечаний.
- Все 10 таблиц public: RLS включён.
- tests/rls.sql выполнен через Supabase в одной транзакции с rollback: три временных auth.users, bootstrap, создание/изменение/удаление заметки, создание события, заявка и принятие, уникальность пары, переписка, серверные уведомления. Проверены запреты чтения чужих notes/events, чтения/отправки messages посторонним и изменения чужого профиля. Пользователи не сохранялись. Это проверка БД под authenticated, а не end-to-end Auth.
- Playwright: 5 тестов прошли. Вход/переключение регистрации и защита маршрута без сессии; рабочий кабинет, создание заметки, открытие чатов/настроек на 1440 и 390 px. Для авторизованного интерфейса использован mock транспорта, не настоящая авторизация.
- Скриншоты docs/auth-*, dashboard-*, chats-*, settings-* созданы на тестовых UI-фикстурах. В приложении фиктивные данные отсутствуют.

## Не проверено на живом API — блокирует выпуск

Среда разрешает GitHub/пакетные реестры, но не домен API Supabase. SQL MCP работает отдельно. Изменить политику самостоятельно доступным инструментом нельзя; запрошено разрешение домена проекта. Ниже нельзя считать пройденным:

1. Реальные регистрация, email confirmation, вход, refresh, восстановление, выход.
2. CRUD через HTTP Data API из браузера (SQL-пути проверены отдельно).
3. Realtime между двумя браузерными аккаунтами, reconnect и гонки подписок.
4. Storage upload, замена аватара и signed URL в браузере.
5. Два реальных пользователя: запрос дружбы, принятие, чат, уведомления и чужой профиль.
6. Реальный iPhone/Safari, экранная клавиатура и медленная сеть (Chromium 390 px проверен).
7. Production redirect URLs и доставка email, публикация Pages.

## Известные ограничения текущей ветки

- Первичная загрузка ограничена 500 записями на таблицу и 200 профилями. Полная пагинация заметок/событий/уведомлений и отдельная загрузка чужого профиля за этим пределом требуют доработки. Поиск заметок локальный внутри загруженного набора; поиск пользователей серверный, до 20 результатов.
- История чата загружается по 50 с кнопкой предыдущих; это повторная загрузка увеличенного окна. Сортировка переписок по последней активности/превью ещё не реализована.
- Нет offline-очереди, автоматического сохранения, удаления аккаунта или смены email. Управление аккаунтом включает восстановление пароля и выход.
- Дубликаты Realtime предотвращаются перечитыванием массива, но идемпотентный retry при неоднозначном сетевом исходе отправки сообщения требует доработки.
- Сборка выдаёт предупреждение use client для lucide-react; это директива React Server Components, клиентский runtime её не использует.

Ветка подготовлена для ревью как draft. До закрытия этих пунктов не объединять и не публиковать вместо действующего сайта.
