## Известные ограничения текущей ветки

- Первичная загрузка по 50 записей с кнопками «Загрузить ещё» для заметок, событий, категорий, друзей, переписок и уведомлений. Профили загружаются по ID связанных участников; чужой профиль запрашивается отдельно по маршруту. Автообновление возвращает окно к первой странице. Поиск заметок выполняется через invoker RPC по всем личным заголовкам, текстам и тегам с пагинацией по 50. Категории, избранное и сортировка применяются на сервере. Поиск пользователей серверный, до 20 результатов. Календарь отдельно выбирает диапазон видимых 42 дней, по 100 событий с кнопкой продолжения. Ближайшие события загружаются отдельно от архива.
- История чата загружается страницами по 50 по паре created_at/id; старые страницы объединяются без дубликатов. RPC conversation_summaries (SECURITY INVOKER) возвращает последнее сообщение и точное число непрочитанных по read_receipts. Список загруженных переписок сортируется по активности, добавлено превью.
- Нет offline-очереди, автоматического сохранения, удаления аккаунта или смены email. Управление аккаунтом включает восстановление пароля и выход.
- Повторная отправка после сетевой ошибки использует прежний UUID. Конфликт подтверждается чтением и сравнением существующей записи. Playwright проверяет сохранение на сервере с потерянным ответом, retry и единственный bubble. Realtime объединяет сообщения по UUID.
- Сборка выдаёт предупреждение use client для lucide-react; это директива React Server Components, клиентский runtime её не использует.

Ветка подготовлена для ревью как draft. До закрытия этих пунктов не объединять и не публиковать вместо действующего сайта.
