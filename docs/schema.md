# Схема и доступ

Все 10 таблиц public имеют RLS, доступ без сессии отсутствует.

| Таблица | Назначение | Доступ |
|---|---|---|
| profiles | Имя, bio, путь аватара, discoverable | Авторизованные читают; владелец обновляет |
| settings | Уведомления сообщений/друзей | Только владелец |
| categories | Личные категории | Только владелец |
| notes | Текст, теги, избранное, даты | Только владелец; составной FK исключает чужую категорию |
| events | Начало/конец timestamptz, исходная IANA timezone | Только владелец |
| friendships | Заявки pending/accepted | Только участники; принять может адресат; участники неизменяемы через column grants |
| conversations | Два участника, уникальная неупорядоченная пара | Только участники; создание после дружбы |
| messages | Текст и история | Читают участники; отправляет участник при действующей дружбе |
| read_receipts | Последняя дата чтения | Только собственные отметки в своей переписке |
| notifications | Серверные события, отметка прочтения | Только адресат; клиент меняет лишь read |

Уникальный индекс пары дружбы исключает встречные и повторные заявки. Удаление дружбы сохраняет историю, но запрещает новые сообщения до повторного принятия. Отклонение удаляет pending-заявку.

private.bootstrap создаёт профиль и настройки при регистрации. private.notify создаёт уведомления согласно настройкам адресата. Обе функции SECURITY DEFINER ограничены закрытой схемой и отозванным EXECUTE; это внутренние триггеры, не клиентские RPC. Уведомления проверяют auth.uid(). Обновление updated_at выполняет invoker-триггер.

Аватары в private bucket avatars: JPG/PNG/WebP до 2 МБ. Только владелец папки uid может писать/обновлять/удалять; авторизованные могут получать signed URL. Срок URL — час. Realtime publication включает messages, notifications, friendships; доставка Postgres Changes подчиняется RLS. UI удаляет каналы при размонтировании/смене сессии/переписки.

События вводятся в часовом поясе устройства и сохраняются в UTC с исходной IANA зоной. Отображаются в зоне устройства. При путешествии абсолютное время сохраняется. Повторяющиеся события не реализованы.

## Сводка переписок

Миграция 20261103144639_conversation_summaries.sql применена к этому же проекту. public.conversation_summaries — SECURITY INVOKER, search_path пустой, EXECUTE отозван у PUBLIC/anon и выдан authenticated. Возвращает только переписки текущего участника с последним сообщением и непрочитанными по read_receipts; RLS применяется ко всем источникам.

public.search_notes — invoker RPC поиска по личным заметкам (заголовок, текст и теги), фильтрации категорий/избранного, сортировки и страниц по 50. Вызов разрешён только authenticated; явная проверка user_id=auth.uid() дополняет RLS. Ввод ищется как буквальная подстрока, а не как SQL-шаблон.
